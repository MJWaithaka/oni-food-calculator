# ONI Food Calculator

A lightweight, static food-planning calculator for *Oxygen Not Included*. Select a food and set colony conditions to see the renewable inputs required per cycle.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy

The project has no build step. Enable GitHub Pages from the repository's default branch with `/ (root)` as the publishing folder.

## Notes

The recipe model and calculation behavior were reconstructed from the archived Oni Assistant Food Calculator. This is an independent, static implementation and is not affiliated with Oni Assistant or Klei.
